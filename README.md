# Modern Skill Educational Trust (MSET)

Educational NGO website — free education, skill training, women empowerment.

## Pages
- `index.html` - Home
- `about.html` - About, team, legal
- `courses.html` - Free courses
- `admissions.html` - Admission form
- `donate.html` - Donate (80G)
- `gallery.html` - Gallery
- `volunteer.html` - Volunteer form
- `contact.html` - Contact + FAQs

## Run locally
Just open `index.html` in browser. No build needed.

Or with VS Code Live Server / python:
```
python -m http.server 8000
```

## Tech
Pure HTML + CSS + JS (`css/style.css`, `js/main.js`)
